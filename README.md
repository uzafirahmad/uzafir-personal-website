# Uzafir A. Rafaq — Portfolio

A single-page portfolio built with Next.js, React, and TypeScript. The layout is inspired by Stripe's resources page: a sticky category rail links to anchored content sections on one continuous page.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run build
```

## Page sections

The anchored sections appear in this order:

1. Links
2. Research Profile
3. Education
4. Projects
5. Skills
6. Invited Talks
7. Experience
8. Publications

Links such as `/#projects` jump directly to a section while preserving the single-page experience.
